# Decision 506 — std gains a CLI's host primitives (`io.stdin`, `io.terminal`, `io.process` signals and `spawn`), and a new `cli` library (`botopink/cli`) builds typed commands, style and prompts over them; onze uses it.

The program is `rakun-ssr start` (onze's `start`) written over the two halves the decision splits. The `cli` library makes the command types-first: `Start` is a record marked `#[cli.command("start", about: …)]`, its fields a `#[cli.flag(short: "p")]` port and a `#[cli.arg]` directory with their defaults, and `cli.parse<Start>(env.args())` answers the typed value — or an error naming the flag and the type, here caught to fall back on the defaults. Its style is plain functions, `cli.style.bold`, `dim`, `green`, `red`, which emit nothing under `NO_COLOR` or when stdout is no TTY. Everything that touches the host comes from std: `stdin.isTTY()` and `terminal.stdoutIsTTY()` tell whether a person is there, `terminal.size()` answers `?#(i32, i32)` (80 columns when there is no terminal), `onSignal(Signal.Hup, …)` hangs a handler on `SIGHUP`, and `spawn("node", …)` answers `Result<Child, ProcessError>`. The child's `forwardSignals()` passes `SIGINT`, `SIGTERM`, `SIGHUP` and `SIGWINCH` on to the node, so a Ctrl-C stops the server and not only its parent, and `await child.wait()` answers its exit code. The same primitives behave alike on commonJS, erlang and beam, and are a located refusal on wasm. On a run with no `node` on the path the program prints the `could not start node` line with the `ProcessError`.

Cells in this repository that prove it: none yet. The `cli` library (`botopink/cli`) has no repository yet, and rakun-ssr's `start` spawning its node over `forwardSignals()` and `create`'s prompts are front 150's steps-onze (162's work, decision 506 (3)).
