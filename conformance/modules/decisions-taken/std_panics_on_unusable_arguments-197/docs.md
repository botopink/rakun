# Decision 197 — † (1) erlang's `indexOf` / `lastIndexOf` count codepoints (320).

The example walks the four points with the pieces of std a rakun application leans on. (1)
`"ação/ação".indexOf("/")` is `4` and `lastIndexOf("ç")` is `6`: erlang counts codepoints like
every other target. (2) A retry policy with `maxAttempts: 0` can never run its work: `nextDelay`
answers `null` for it, and `retry` panics with `async.retry: maxAttempts must be at least 1 (the
first attempt)` instead of answering an `Error` the caller could mistake for the work's own —
`attemptTask` catches it as a `Failure` of kind `panic`. (3) `hash.pbkdf2Sha256` with zero iterations
panics with `hash.pbkdf2Sha256: iterations and length must be at least 1`, one text on every
target, never the host's own raise. (4) Over a scratch tree `static/css/app.css`,
`static/logo.svg`: `static/**` is every entry below `static` at every depth, the root itself
excluded, so `3`; `static/*/` keeps real directories only, so it lists `static/css` alone and not `logo.svg`; and the alternative
`{css/app,logo}` holds a `/`, so it matches nothing, `0`.

Proving cells: none in this repository; these are std's (`02/97`), proved by botopink-lang's cells.
