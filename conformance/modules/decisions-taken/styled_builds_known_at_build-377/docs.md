# Decision 377 — `styled` builds at build what is known at build, fills the rest at render, and registers a component in the render's sheet where it is used, never where it is made.

The example is an application of `rakun-style` whose page provides the render's sheet, a writer that prints each registration. `mono`'s holes are all known at build — `${padAll(2)}` splices a `StyledProperty` whose own hole is the literal `2` —, so it is a constant: its class and its rules, `font-family:mono;padding:calc(var(--spacing) * 2)`, are written while the program is built. `label`'s literal has one hole of the render, its parameter `cor`: at build it is parsed, checked and its known hole computed, so the template already holds `padding:calc(var(--spacing) * 2)` and one slot; rendering `label("teal")` only fills the slot with `teal`, hashes and registers. Which hole is known is the compiler's mark on each hole (`p.hole.known`, and `p.hole.why` when not — `cor` is a parameter, `BANNER_COLOR` an environment read), never a guess of the library. `banner` is a module `val` whose hole reads `env.read`: it is legal, computed when the module loads, and registered only where `Page` uses it. Every registration happens at a use — `use mono`, `use banner`, `use label("teal")` — through the `StyledContext` `Page` provides; `main` makes `label("green")` outside every provider and never uses it, so nothing is read and nothing is registered, and the program prints `made, not used` first, then one `registered …` line per use and the three classes.

Departure: `rakun-style`'s `styledComputed` reads `StyledContext` and adds to the sheet where the literal is computed, not where it is used, so a render-hole literal computed outside every provider aborts naming the missing provider; it splices the whole literal at render, with no template of slots computed at build; and `use` of a `styled` value is refused with `use-of-non-context-fn` (as [styled_registers_where_used-352](../styled_registers_where_used-352/docs.md) records). The build half is `01-compiler/14` step 8 and front 119 step 1.

Cells in this repository that prove it: none yet. The drafts [styled_literal_computed_at_build-355](../styled_literal_computed_at_build-355/docs.md) and [styled_registers_where_used-352](../styled_registers_where_used-352/docs.md) show the two halves this decision amends.
